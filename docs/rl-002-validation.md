# RL-002 Validation

Validation covers dependency qualification, target/calibration identity, allowed
estimators, confidence intervals, effective sample size, importance weights, estimator
agreement, action overlap, extrapolation, unsupported-action abstention, independent
reward-model rebuild, adversarial reward, support trimming, weight clipping, cost stress,
idempotency and exact replay.

The deterministic live fixture demonstrates the conservative gate only. A
`shadow_eligible` decision is not a causal claim, production promotion, deployment,
order permission or capital authority.
