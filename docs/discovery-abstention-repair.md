## Changes

- New hypothesis output requires `abstention`: null for proposals, otherwise an
  explanation containing reason code, evidence, owner and recovery condition.
  New unexplained empty responses are rejected. The controller retains historical
  empty responses as `legacy_reason_not_recorded`, never inventing a reason.
  Explanations are model-reported, explicitly not verified adjudications.
- Context declares `new_scientific_design`, `frozen_source_recovery` or
  `scientific_method_correction`, derived from the existing typed scope. Prose
  cannot select a recovery mode or authorize relaxing frozen requirements.
- The prompt distinguishes proposed ex-ante design assumptions from observed
  effects and verified equations. Proposed assumptions require rationale,
  sensitivity analysis and independent review; they do not authorize changing an
  old specification or bypassing novelty checks.
- Requirements/feasibility objectives add bounded method-specific hybrid retrieval
  queries for power, precision and serial dependence. This does not guarantee
  relevant hits; query receipts and citation provenance remain necessary.
- When exact instrument names are explicitly selected in founder context, only
  their detailed availability rows enter the prompt. Omission counts, selection
  basis and the original catalogue receipt are retained. Unscoped discovery keeps
  the full inventory. Receipt provenance refers to the full source catalogue,
  not a claim that the selected view is a separately admitted dataset.

queries ranked book indexes highly. Shorter queries, `statistical power sample size`

remaining passages still require relevance assessment and mathematical assurance.
