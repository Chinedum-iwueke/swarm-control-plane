# GOV-003 validation

GOV-003 is complete when promotion, demotion, quarantine, retirement and reinstatement
are closed typed consequences against one GOV-002 projection; every accepted command
binds a current GOV-001 authority decision, fresh evidence, accountable and independent
participants, bounded expiry, rollback state and affected descendants; invalid or stale
commands fail closed; reversal and expiry append new events rather than deleting
history; Mission Control exposes retained consequences; and a live no-capital pilot
proves promotion rollback, quarantine/reinstatement and retirement/reinstatement.
