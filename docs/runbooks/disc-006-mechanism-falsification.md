# DISC-006 Mechanism and Falsification Service

Freeze the mechanism plan before observing decisive-test outcomes. Each plan binds an
active DISC-002 mechanism/opportunity map, registered hypothesis, RI dossier and
opposition records, assumptions, alternatives, confounders, observable predictions,
null expectations and explicit falsification conditions.

Evaluations must cover every preregistered test exactly once, use canonical evidence,
postdate the plan and report outcomes for every targeted rival. The service computes:

- `falsified` when any decisive test fails;
- `supported` only when all tests pass and every rival is ruled out;
- `unresolved` for incomplete, inconclusive or surviving-rival evidence.

Supporting evidence cannot override a failed decisive test. Corrections supersede an
evaluation; they never mutate or delete the earlier outcome. This service has no
strategy-generation, execution, order or capital authority.
