# RL-001 Validation

Validation covers immutable dataset binding, sealed no-capital shadow evidence, behavior
policy identity and propensities, complete action support, causal state/reward timing,
independently rebuilt rewards, episode termination, confounder limitations, estimator
separation, abstention, quarantine behavior, idempotency, and exact API replay.

Adversarial cases include support gaps, propensity omissions, excessive importance
weights, timestamp disorder, state/reward leakage, reward rebuild mismatch, action-space
mismatch, and contract digest drift. The live fixture proves the contract path only; it
does not estimate a new policy's value or grant any operational authority.
