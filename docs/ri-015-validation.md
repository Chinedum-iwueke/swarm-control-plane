# RI-015 Validation

Source completion requires:

- immutable suite, run and item-result records;
- hidden gold labels absent from list/readiness APIs;
- exact manifest coverage and independent evaluator enforcement;
- deterministic evidence-bound scoring across all declared reasoning dimensions;
- applicability-aware aggregates that cannot be inflated by irrelevant tasks;
- stale corpus/projection failure closure;
- explicit historical metric-regression failure closure;
- per-domain qualification, limitations and representative failure surfaces;
- a synthetic contract pilot spanning all 13 Research Bible domains and ten task
  classes without claiming live intelligence qualification;
- Mission Control display of status, claim boundary, domain scores, limitations
  and representative-failure counts.

The first contract pilot is engineering evidence only. RI-015 production
qualification additionally requires an independently authored live-corpus suite
and real runtime responses. Until that exists, the correct institutional state is
`not_demonstrated` even when the evaluator itself is `contract_validated`.
