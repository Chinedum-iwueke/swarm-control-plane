# AGT-001 validation

The milestone is accepted when the migration upgrades and downgrades cleanly, all
backend regressions pass, Mission Control can display active charter/grant state, and
the production pilot proves the same bounded request is allowed before grant
revocation and denied afterward.

The retained pilot report binds the agent, signed role package, immutable charter,
grant, pre-revocation permission snapshot and post-revocation denial. It explicitly
records that no capital or order authority was created.
