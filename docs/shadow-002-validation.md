# SHADOW-002 validation

Hermes registers the immutable Bulletproof monitoring specification and admits only
the exact authoritative SHADOW-002 receipt. It does not recalculate prospective
health. The receipt exposes current status, deterioration, stale-evidence behavior
and the next review time for downstream lifecycle and observability consumers.

Lifecycle changes remain proposals for independent GOV-003 authority. Registration
does not allocate capital, place an order, promote, demote or reactivate a candidate.
